# Third-party files

`ossie-schema.json` is the Apache Ossie (formerly Open Semantic Interchange, OSI) core metadata
JSON Schema, copied unchanged from https://github.com/apache/ossie at commit
`e49a0f0ca2336669ba22662853eba63bff3ce8d1` (`core-spec/ossie-schema.json`, spec version
`0.2.0.dev0`, a draft that may change before 0.2.0 is released).
